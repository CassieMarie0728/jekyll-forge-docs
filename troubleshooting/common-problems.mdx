## Sign-in loops

For the hosted app, start from its current HTTPS address. For a self-hosted app, check `APP_URL`, the GitHub OAuth callback, and the configured secrets. Local OAuth should use the API origin on port 8787 rather than an unrelated preview port. Never share session cookies or tokens in a bug report.

## Report enough information to reproduce

Include the page, approximate time and timezone, browser/device, operation, expected result, actual error, and whether the remote file changed. Include a minimal non-sensitive example if content triggers the problem.

Remove tokens, cookies, account secrets, private manuscript text, and private repository contents. A screenshot of a key is still a leaked key even if the caption says “please ignore this.”

## Do not start with destructive fixes

Do not delete the database, clear browser storage, reset the repository, or repeatedly rotate secrets to troubleshoot a UI failure. Preserve work, identify the failing layer, and make the smallest targeted correction.
