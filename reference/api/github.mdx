## github.updateJekyllConfig

**Mutation · `protectedProcedure`**

[Handler and return value](https://github.com/CassieMarie0728/jekyll-forge/blob/c889b55402f374d832b2412d9ce1a32c5fae06a7/server/routers/github.ts#L570).

```typescript
z.object({
        owner: z.string(),
        repo: z.string(),
        rootPath: z.string().default(""),
        branch: z.string().default("main"),
        /** Set a new theme */
        theme: z
          .string()
          .regex(/^[a-zA-Z0-9][a-zA-Z0-9_-]*$/)
          .optional(),
        /** Add a plugin (appended to plugins list) */
        addPlugin: z
          .string()
          .regex(/^[a-zA-Z0-9][a-zA-Z0-9_-]*$/)
          .optional(),
        /** Remove a plugin */
        removePlugin: z
          .string()
          .regex(/^[a-zA-Z0-9][a-zA-Z0-9_-]*$/)
          .optional(),
        commitMessage: z.string().optional(),
      })
```
