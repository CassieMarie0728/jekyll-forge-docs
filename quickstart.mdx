---
title: "Your first saved draft"
description: "Go from sign-in to a saved draft without accidentally publishing your smoke test."
---

You need a GitHub account, a Jekyll repository you can access, and a repository token with the appropriate permissions. You do not need an AI key to write.

<Steps>
  <Step title="Open Forge and sign in">
    Open [Jekyll Forge](https://jekyll-forge.c728.workers.dev/repos) and complete GitHub sign-in. You should return to the repository picker. If sign-in loops or fails, use [access troubleshooting](/guides/github-access).
  </Step>
  <Step title="Connect repository access">
    Connect your GitHub Personal Access Token through the repository connection controls. OAuth sign-in and repository access are separate. Confirm the displayed GitHub account before continuing.
  </Step>
  <Step title="Choose the destination">
    Find your repository, select its branch, and confirm the site root. A repository with many files may need more result pages; a Jekyll site can live in a subfolder.
  </Step>
  <Step title="Write a harmless draft">
    Choose **New Post**, enter a recognizable title such as “Forge smoke test,” and write a few lines. Check the post details and front matter before saving.
  </Step>
  <Step title="Save and reopen">
    Click **Save** and wait for success. Open the post list, locate the draft, and reopen it. Confirm both the body and title survived. A browser recovery message alone does not establish this result.
  </Step>
</Steps>

## Your first success signal

The draft appears in the correct Forge workspace and reopens with your text. You have not published a website merely by saving it. Congratulations: the smoke test can remain mercifully invisible to the internet.

## Before your first real publication

Read [Review and publish](/guides/publishing), choose an appropriate test repository or branch, and inspect the exact destination diff. After committing, check the Jekyll deployment and the public URL.

## If the draft is missing

Stay in the same browser. Check **Recovery drafts**, the save status, and the active workspace. Download recoverable work before clearing storage or changing profiles. Follow [Save, recover, publish](/guides/drafts-and-recovery).
