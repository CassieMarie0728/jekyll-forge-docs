# Jekyll Forge field manual

Mintlify documentation for the Cloudflare-hosted Jekyll Forge application, with the author's Deadpool-cool voice and source-linked technical reference.

## Preview and validate

Use the installed Mintlify CLI: `mint dev`, `mint validate`, and `mint broken-links` from this directory. The default preview is http://localhost:3000. Avoid starting a duplicate server if that port is already serving this checkout.

## Publish

The owner connected CassieMarie0728/jekyll-forge-docs, branch main, to the jekyll-forge-docs Mintlify site. Push reviewed changes to that branch and inspect deployment results. The connector's visible site list may not include this new deployment; do not modify another site instead.

## Evidence

Read reference/current-state.mdx for the source revision and acceptance boundaries. DOCS_MANIFEST.json inventories generated pages and evidence links. User guides distinguish recovery, saved drafts, and GitHub writes. API pages reproduce source input schemas and link handlers; they are not a stable public API promise.
